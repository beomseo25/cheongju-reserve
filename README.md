# cheongju-reserve

청주시 통합예약(ticket.cheongju.go.kr)에서 체육시설 예약 순서를 대신 눌러 주는 Tampermonkey 유저스크립트입니다. (prototype)

> 현재 버전: **0.8 (prototype)** — 완성되면 1.0

## 하는 일
상세 페이지에서 `▶ 시작(대기)` 한 번 → 대상 달의 지정 요일(기본 일요일) 날짜마다 창을 하나씩 열고, 접수 시각(서버시간)에 맞춰 동시에
신청하기 → 순번대기 → 날짜/시간 선택 → 약관 동의 → 신청자 정보 입력 → 신청까지 진행합니다.

- **서버시간 동기화**: Date 헤더로 서버-PC 시계 차이를 ms 단위로 측정 (navyism 방식)
- **컨트롤러 창**: 시작 버튼을 누른 원래 창은 예약은 하지 않고 시간 측정·감시·복구만 담당
- **순번대기(NetFUNNEL) 대응**: 대기열에 서 있는 동안 절대 새로고침하지 않음. 대기열을 우회하지 않음
- **실전 대응**: 접수 전 튕김 → 간격을 두고 재클릭, 서버 오류(503/404) → 같은 단계 재시도, 연결 끊김·멈춤 → 컨트롤러가 그 창만 다시 시작,
  최종 신청에서 선점됨 → 다음 시간대(`SLOTS`) 시도
- **중복 예약 방지**: 최종 신청은 절대 다시 제출하지 않음. 결과가 불명확하면 ⚠ 표시 후 멈춤(예약확인에서 직접 확인)
- **안전장치**: 정보 입력 화면의 예약일자가 내 날짜와 다르면 신청하지 않음

## 설치와 사용
1. 크롬에 Tampermonkey 설치 (`chrome://extensions` 개발자 모드 켜기)
2. **예전 버전 스크립트는 삭제**하고, 새 스크립트에 `cheongju_reserve.user.js`를 붙여넣어 저장
3. 맨 위 `CFG`의 `GROUP`, `PEOPLE`, `EMAIL_ID`, `EMAIL_DOMAIN` 수정 (`WEEKDAY: 0` = 일요일, `SLOTS` = 원하는 시간대)
4. 주소창 자물쇠 아이콘 → 사이트 설정 → **팝업 및 리디렉션: 허용**
5. 로그인 후 해당 달의 시설 상세 페이지에서 `▶ 시작(대기)` → 날짜별 창이 화면 오른쪽 3/4에 타일로 열림
6. 처음에는 반드시 `DRY_RUN: true`로 리허설 (`OPEN_AT: ''`이면 즉시 진행). `false`면 **실제로 신청**됩니다.

접수 시각까지 PC 절전 해제, 창 최소화 금지. 화면 왼쪽 1/4은 컨트롤러 창이 보이도록 비워 둡니다(완전히 가려진 창은 타이머가 느려짐).

## 결과 표시
`✅ 완료 예약번호` / `❌ 마감·선점됨` / `⚠ 직접 확인 필요`(최종 신청 후 응답 없음 등 — 예약됐을 수 있음) / `DRY_RUN 정지`.
예약마다 7일 안에 무통장입금이 필요합니다.

## 테스트
`test/mock08.js`: 순번대기·접수 전 튕김·응답 지연·503·연결 끊김·AJAX 오류·경쟁자 선점을 흉내 낸 모의 사이트에서 병렬 신청을 검증합니다.
```
node test/mock08.js cheongju_reserve.user.js <seed> [dry]     # CHAOS=1: 오류율 상향, EARLY=1: 1.5초 일찍 클릭, PREOPEN=disabled
```
(Playwright + Chromium 필요. 경로는 파일 안에서 수정)

## 하지 않는 것
캡차/로그인 우회, 순번대기 우회, 여러 계정 사용, 입금.

## 사용 책임
개인 계정으로 본인의 예약에만 사용하세요. 사이트 이용약관·운영 정책을 확인하고 지키는 것은 사용자 책임입니다. 사이트 구조가 바뀌면 동작하지 않을 수 있습니다.
