# cheongju-reserve

청주시 통합예약(ticket.cheongju.go.kr)에서 체육시설 예약 순서를 대신 눌러 주는 Tampermonkey 유저스크립트입니다. (prototype)

> 현재 버전: **0.6 (prototype)** — 완성되면 1.0

## 하는 일
접수 시작 시각 대기 → 신청하기 → 날짜/시간 선택 → 약관 동의 → 다음 → 신청자 정보 입력 → 다음(신청)

- **서버시간 동기화 (0.6~)**: 대상 사이트의 Date 헤더를 여러 번 받아 서버-PC 시계 차이를 ms 단위로 측정하고, 서버시간 기준 정각에 클릭합니다. (navyism 방식)
- 시간대 우선순위(`SLOTS`), `DRY_RUN`(마지막 "다음" 직전에서 정지), 재시도 새로고침

## 설치와 사용
1. 크롬에 Tampermonkey 설치 후 `chrome://extensions`에서 **개발자 모드** 켜기
2. Tampermonkey → 새 스크립트 → `cheongju_reserve.user.js` 내용 붙여넣기 → 저장
3. 파일 맨 위 `CFG`를 본인 값으로 수정 (`OPEN_AT`, `TARGET_DATE`, `SLOTS`, `GROUP`, `EMAIL_ID`/`EMAIL_DOMAIN` …)
4. 예약 상세 페이지에서 "⏱ 서버시간 측정"으로 확인 → "▶ 시작(대기)"
5. 처음에는 반드시 `DRY_RUN: true`로 리허설. `false`면 마지막 "다음"까지 눌러 **실제로 신청**됩니다.

대기 중에는 이 탭을 맨 앞에 두세요. 크롬이 백그라운드 탭의 타이머를 늦춥니다.

## 하지 않는 것
캡차/로그인 우회, 여러 계정·여러 창 동시 신청, 입금. 로그인은 미리 해 두어야 하고 입금은 직접 해야 합니다.

## 사용 책임
개인 계정으로 본인의 예약에만 사용하세요. 사이트 이용약관이 자동화를 금지할 수 있고, 위반에 따른 예약 취소·이용 제한 등은 사용자 책임입니다. 저장소의 `CFG` 값은 예시이며 사이트 구조가 바뀌면 동작하지 않을 수 있습니다.
